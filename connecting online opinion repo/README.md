## Reproducing All Analyses

Tested with **Python 3.12.7**, `numpy==1.26.4`, `pandas==2.3.3`, `scipy==1.13.1`, `statsmodels==0.14.2`, and `matplotlib==3.9.2`. Install dependencies cleanly:

```bash
pip install -r requirements.txt
```

### 1. Run the Complete Analysis Notebook (~2 min)

Execute from the repository root or `code/` (`find_repo_root()` resolves paths automatically):

```bash
jupyter nbconvert --to notebook --execute code/www_short_analysis.ipynb --output www_short_analysis_rerun.ipynb
```

- When `results/www_short/confirmatory/` already exists, executing `MODE = 'confirmatory'` writes a timestamped verification copy to `results/www_short/confirmatory_<timestamp>/` without overwriting the shipped confirmatory outputs.
- Set `QUICK = True` in Cell 1 for a `~20 s` smoke test (`B_BOOT = 200`, `R_NULL = 50`).
- Set `MODE = 'dry_run'` in Cell 1 to test the outcome-permuted null pipeline into `results/www_short/dry_run/`.

### 2. Regenerate Figures and Summary Tables

From the repository root:

```bash
python code/scripts/make_fig_mechanism.py figures/fig_mechanism.pdf
python code/scripts/make_fig_sd.py figures/fig_sd_by_domain.pdf
python code/scripts/make_fig_assoc.py figures/fig_assoc.pdf
python code/scripts/make_tables.py
python code/scripts/derived_numbers.py
```

`derived_numbers.py` writes [`results/www_short/derived/admin_outcome_side_split.csv`](results/www_short/derived/admin_outcome_side_split.csv) and [`results/www_short/derived/derived_numbers.txt`](results/www_short/derived/derived_numbers.txt).

## Data Provenance and Limitations

1. **Archived inputs only:** Raw Reddit comment texts (`fh-bigquery.reddit_comments.*`, 2015–2019) and per-keyword mention counts were not stored alongside the city-to-keyword sentiment array (`data/city_aspects.npy`). Accordingly, total retained dictionary entries per city serve as the corpus-size proxy $s_i$ (verified invariant after removing all 145 scored study keywords, $r = 1.000$).
2. **Sample:** Starting from `data/census_cities.csv` (49 metros) and `data/city_aspects.npy` (40 cities), excluding 9 non-Reddit metros plus Washington and Birmingham per the baseline specification yields the **38-city** analysis sample (`results/www_short/preprocessing/analysis_design_38_cities.csv`).
3. **Zero-observation study keywords:** Two listed terms (`concert`, `fraud`) never exceeded the 10-mention threshold in any of the 38 sample cities (`observed keywords = 143` across 1,811 retained city–keyword cells).
4. **Proprietary Walk/Transit/Driving Score scales:** Values in `census_cities.csv` were rescaled prior to archiving and are not on a 0–100 Walk Score range; `Walking Score` and `Driving Score` enter the archived 11-indicator model and RQ2 comparisons, while `Transit Score` enters only exploratory transport checks.
